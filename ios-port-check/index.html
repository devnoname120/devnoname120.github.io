A QUICK FIELD GUIDE

Which games are worth a look?

Clues to explore. Not automatic verdicts.
01 / THE ERA

Start with the classics.

Games released around 2007–2016 are a useful place to look. An older version may keep ARMv6 or ARMv7 code that a newer update dropped.

Older versions can matter
02 / THE HARDWARE

Think early iPhones.

Games that ran on the original iPhone, 3G, 3GS, 4, or 4S are promising. iPhone 5 and 5C titles need a closer look at memory use.

Check the binary, not the phone
03 / THE DEPENDENCIES

Less Apple. More game.

Games with fewer Apple UI and platform dependencies tend to be better candidates. A supported ARM architecture is only the first piece of the puzzle.

Manual review still needed
What this check can — and can’t — tell you +

“Portable” means an ARMv6 or ARMv7 executable was found in this version. We inspect the actual main Mach-O executable, including universal binaries. We don’t infer compatibility from the game’s age, metadata, or supported devices. ARMv5, ARMv7s, and ARM64 alone do not pass this check.

Original iPhone and iPhone 3G games use ARMv6, which passes the architecture check. Running on an iPhone 5S or later also doesn’t prove a game is ARM64-only: older universal versions can include ARMv6 or ARMv7. iOS 11 stopped launching 32-bit apps, so minimum iOS is a useful clue, not the verdict.

Actual porting still requires engineering work and review of memory, graphics, iOS APIs, and any binary encryption. This tool does not execute, modify, or port the game. Missing or invalid executables produce an inspection error rather than a negative verdict.

Release dates appear only when the IPA explicitly includes release metadata. ZIP timestamps, purchase dates, and signing dates are never used as release dates.

IPAs are read in a local browser worker. SHA-256 covers every byte of the original IPA and every byte of its decompressed main executable, including all architecture slices. File contents and hashes stay on your device.

The App Store icon lookup sends only the bundle ID from the IPA to Apple’s US lookup service. When an exact match is found, the Markdown includes a public artwork URL from the current listing; its icon may differ from this older version. A delisted app or an unavailable lookup leaves the report without an icon.
